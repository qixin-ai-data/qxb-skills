# 自然语言任务转译

## 用途

把用户输入的中文自然语言关系寻源需求转成稳定的结构化 JSON，供后续寻源流程继续执行。

仅当输入是自然语言对话、聊天消息或非结构化说明时读取本文件。
如果上游已经提供了结构化任务对象，则直接进入寻源流程，不要重复转译。

## 使用方式

先把原始用户请求完整保留到 `raw_query`，再按本文件规则输出标准结构。
若关键信息缺失，不要猜测，必须保留为空值并标记 `missing=true`。

## 强制规则

1. 只产出合法 JSON。
2. 不要输出 Markdown。
3. 不要输出解释、注释、前言或后记。
4. 输出字段必须完整，不要省略字段。
5. `benchmark_enterprise`、`product_query`、`target_regions` 是必填字段；缺失时必须进入 `missing_required_fields`。

## 任务目标

尽量从自然语言中提取以下信息：

- 标杆企业
- 产品或品类
- 目标国家或地区
- 采购场景
- 补充线索
- 长名单目标数量（默认10-20家）
- 筛选偏好

## 默认值

如果用户没有明确提及，可使用以下默认值：

- `procurement_scenario`: `"替代供应商"`
- `result_target.longlist_min`: `10`
- `result_target.longlist_ideal`: `20`
- `result_target.shortlist_target`: `5`
- `filters.active_only`: `true`
- `filters.require_contact`: `true`
- `filters.exclude_invalid_entities`: `true`
- `filters.manufacturing_preferred`: `true`

## 地区标准化

将自然语言地区转成标准代码数组：

- 中国 -> `CN`
- 中国台湾 / 台湾 / 台灣 -> `TW`
- 中国香港 / 香港 -> `HK`
- 中国澳门 / 澳门 -> `MO`
- 韩国 / 南韩 -> `KR`
- 日本 -> `JP`
- 新加坡 -> `SG`
- 马来西亚 -> `MY`
- 泰国 -> `TH`
- 越南 -> `VN`
- 印度 -> `IN`
- 美国 -> `US`
- 加拿大 -> `CA`
- 德国 -> `DE`
- 法国 -> `FR`
- 英国 -> `GB`
- 墨西哥 -> `MX`

区域概念展开为：

- 日韩台 -> `["KR", "JP", "TW"]`
- 中日韩 -> `["CN", "JP", "KR"]`
- 东南亚 -> `["SG", "MY", "TH", "VN", "ID", "PH"]`
- 北美 -> `["US", "CA", "MX"]`
- 欧洲 -> `["DE", "FR", "GB", "IT", "ES", "NL"]`

如果无法可靠映射，则保留为空数组，并标记 `missing=true`。

## 产品词规则

- `raw_text` 保留用户原始产品词
- `aliases` 仅在用户明确给出同义表达时填写
- 不要臆造大量扩展词
- 未明确提到产品或品类时，`raw_text` 置空并标记 `missing=true`

## 补充线索规则

若用户明确提到以下内容，可放入 `supplemental_clues.value`：

- 候选企业名称
- 竞对企业名称
- 品牌或供应链线索
- 材料、部件、模组、工艺关键词

没有提到时返回空数组。

## 数量规则

- "10家左右" -> `longlist_ideal = 10`
- "20家" -> `longlist_ideal = 20`
- "至少10家" -> `longlist_min = 10`，`longlist_ideal = 20`
- "5家短名单" -> `shortlist_target = 5`

未明确数量时使用默认值。

## 置信度规则

- 明确出现的字段：`0.85` 到 `0.99`
- 可合理映射但有轻微歧义：`0.6` 到 `0.84`
- 缺失字段：`0`

    },
    "target_regions": {

## 与寻源流程的衔接规则

- `ready_to_execute=true` 时，直接进入循环寻源流程。
- `ready_to_execute=false` 时，只追问 `missing_required_fields` 中缺失的字段。
- 不要重复解释转译规则；转译完成后立即进入批次生成或补问。

## 示例

输入：

```
帮我找三星电子在日韩台的光学模组替代供应商，先做20家长名单
```

输出要点：

- `benchmark_enterprise.value = "三星电子"`
- `product_query.raw_text = "光学模组"`
- `target_regions.value = ["KR", "JP", "TW"]`
- `procurement_scenario.value = "替代供应商"`
- `result_target.longlist_ideal = 20`
- `ready_to_execute = true`
