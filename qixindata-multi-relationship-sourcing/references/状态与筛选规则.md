# 状态与筛选规则

## 企业状态判断

### 国内主体状态映射

使用 `cn_company_registration_face` 返回的 `new_status` 字段：

| new_status 值 | 含义 | 是否正常 |
|--------------|------|---------|
| 存续 | 存续企业 | 正常 |
| 在业 | 在业企业 | 正常 |
| 开业 | 开业企业 | 正常 |
| 存续（在册） | 存续企业 | 正常 |
| 吊销 | 吊销企业 | 不正常 |
| 注销 | 注销企业 | 不正常 |
| 撤销 | 撤销企业 | 不正常 |
| 停业 | 停业企业 | 不正常 |
| 歇业 | 歇业企业 | 不正常 |
| 清算 | 清算中 | 不正常 |
| 破产 | 破产企业 | 不正常 |
| 破产重整 | 破产重整 | 不正常 |
| 解散 | 已解散 | 不正常 |

### 香港主体状态映射

使用 `hk_company_info` 返回的 `status` 字段：

| status 值 | 含义 | 是否正常 |
|----------|------|---------|
| Active | 活跃 | 正常 |
| Live | 在港登记 | 正常 |
| Dissolved | 已解散 | 不正常 |
| Struck Off | 已除名 | 不正常 |
| Inactive | 非活跃 | 不正常 |

## 筛选规则

### 硬门槛（直接淘汰）

以下任一条件不满足时，直接淘汰：

1. 企业状态不正常
2. 不在目标地区
3. 没有有效联系方式
4. 明显不属于目标产品或产业链范围
5. 已在排除名单中

### 联系方式门槛

有效联系方式按优先级：

1. 电话（telephone）
2. 邮箱（email）
3. 官网域名（domain_list / websites_list）

三者都没有时，视为无效联系方式。

### 地区匹配规则

- 企业注册地与目标地区完全匹配：完全匹配
- 企业注册地在目标地区邻近区域：邻近匹配
- 企业业务范围覆盖目标地区但注册地不在：业务覆盖
- 两者都不满足：视为不匹配

## 匹配层级定义

### direct（直接匹配）

同时满足：

- 产品或业务与查询词高度相关
- 位于目标地区
- 与标杆企业存在直接供应链或合作关系

### adjacent（邻近匹配）

满足以下之一：

- 产品相关但地理位置略偏离
- 地理位置匹配但产品相关性一般
- 与标杆企业存在二级供应商关系

### exploratory（探索匹配）

满足以下之一：

- 产品线可能相关但无法确认
- 位于目标产业带但缺乏直接关系证据
- 初创企业或新进入者

## 排序分数计算

基础分 100 分，按以下维度扣减：

| 扣减项 | 扣减分值 |
|-------|---------|
| 企业状态异常 | -50 |
| 地区不匹配 | -20 |
| 产品匹配度低 | -15 |
| 缺少联系方式（电话） | -10 |
| 缺少联系方式（邮箱） | -5 |
| 缺少官网 | -3 |
| 风险信号存在 | -5 |
| 成立时间短（<3年） | -2 |

最终分数区间：

- A级（高优先级）：80-100分
- B级（重点关注）：60-79分
- C级（补池候选）：40-59分
- D级（低优先级）：<40分
