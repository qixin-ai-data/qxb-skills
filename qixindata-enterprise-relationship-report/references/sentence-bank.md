# Sentence Bank

## Purpose

本文件用于压缩不同模型的措辞漂移。能复用原句时，不要改写；只替换企业名称、比例、日期、风险类型等变量。

## Conclusion Sentences

### 已确认直接关联

- 公开工商及控制关系资料显示，[主体A] 与 [主体B] 存在明确直接关联关系。
- 公开资料显示，[主体A] 直接持有/控制 [主体B]，可确认两者存在直接关联关系。

### 已确认间接关联

- 公开控制与受益路径资料显示，[主体A] 与 [主体B] 不存在明显直接持股关系，但可确认存在间接关联。
- 基于共同实际控制人/共同受益路径/同一控制体系，[主体A] 与 [主体B] 可确认为间接关联。

### 存在较强关联信号

- 当前公开资料未形成直接控股结论，但已出现较强关联信号，建议结合业务场景继续核验。
- 现有证据显示两主体之间存在较强关联可能，但仍不足以直接确认更高等级关系。

### 当前未检索到足够公开证据

- 当前未检索到足以确认两主体存在更高等级关联的公开证据。
- 基于目前可核验公开资料，暂不宜对两主体之间的关联关系作更高等级判断。

## Evidence Sentences

- [主体A] 的公开股东/投资资料中直接出现 [主体B]，比例为 [比例]。
- [主体A] 与 [主体B] 的实际控制人均指向 [人物]。
- [主体A] 与 [主体B] 的受益路径均可回到 [人物]。
- [主体A] 与 [主体B] 处于同一控制体系/同一集团网络中。
- 关键人物 [人物] 同时连接 [主体A] 与 [主体B]。
- 当前未形成足以进入前三的额外强证据。

## Boundary Sentences

- 本次结论主要建立在公开可核验的工商、股权、控制或受益路径资料之上。
- 当前可核验公开资料有限，未纳入未公开协议安排、内部授权安排或其他非公开控制因素。
- 辅助信号已纳入参考，但未作为本次结论的核心依据。
- 后续如出现股权、管理层、集团结构或重大风险事件变化，建议对本次结论进行动态复核。

## Snapshot Sentences

- 关系快照显示，该主体关联圈规模较大，关系网络相对复杂。
- 关系快照显示，该主体关联圈规模相对集中，控制层级较为清晰。
- 工商风险快照显示，主体公开异常事项整体可控。
- 工商风险快照显示，主体公开记录较多，需结合业务场景持续关注。

## Null Sentences

- 当前公开资料中暂未检索到目标主体之间明确的直接股权或参股控股关系。
- 当前未见足以支持更高等级结论的控制链或受益路径证据。
- 当前未检索到足以影响本次关系判断的重大公开负面事件，不代表相关主体不存在风险，建议持续关注。
- 当前可核验公开资料有限，本章暂未形成进一步明确结论。

## Client Action Sentences

- 建议客户在合作准入、审批、授信、采购或归档口径中，将本次结论作为关联方识别依据之一。
- 建议客户将已识别的关联方一并纳入风险观察范围，而非仅关注单一经营主体。
- 如涉及高敏感业务场景，建议进一步确认上层控制主体、集团母体或关键自然人。
- 后续如出现股权变更、管理层调整、重大处罚或集团结构变化，建议及时复核本次结论。
