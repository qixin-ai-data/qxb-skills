# A 类评分框架

## 目标

把“重点区域里的重点企业发现”稳定成固定口径，不靠临场发挥。先做硬性否决，再打分，再分层。

## 硬性否决

命中以下任一条件时，不进入 `A` 类：

- 企业主体无法确认，或存在多个高相似主体无法排除
- 经营状态为注销、吊销、撤销、清算等非正常存续
- 用户要独立企业主体，但样本明显是分公司、营业部、门店或其他分支
- 区域入口命中，但工商地址已明显迁出目标区域
- 综合风险或司法风险显示明显重负面，影响当前合作稳定性
- 关键字段同时缺失两项以上，例如主体、状态、区域一致性、行业适配依据

## 评分公式

```text
total_score = region_fit + industry_fit + enterprise_strength + innovation_signal + reachability - risk_penalty
```

各维度建议范围：

- `region_fit`: `0-25`
- `industry_fit`: `0-20`
- `enterprise_strength`: `0-20`
- `innovation_signal`: `0-15`
- `reachability`: `0-10`
- `risk_penalty`: `0-25`

## 1. 区域命中度 `region_fit`

看企业是否真的属于本次重点区域：

- 精确命中目标园区或开发区，且当前地址一致：`18-25`
- 命中周边半径、同区域经营明显：`14-20`
- 入口命中，但当前区域一致性还需复核：`8-13`
- 仅弱命中或明显偏离目标区域：`0-7`

优先证据：

- 区域入口本身的命中结果
- 工商照面中的注册地址
- 园区/开发区基本信息中的地区字段

## 2. 行业匹配度 `industry_fit`

看企业是否符合用户要找的产业方向：

- 国民经济行业分类、主营业务和标签都高度匹配：`15-20`
- 主行业大类匹配，但细分赛道仍需人工判断：`9-14`
- 只有经营范围或部分标签弱相关：`4-8`
- 明显不匹配：`0-3`

优先证据：

- `cn_company_industry_nec`
- `cn_company_main_business`
- `cn_company_concept_labels`

如果用户没有明确行业主题，不要因为“行业不明”直接打低分；改为按“产业方向是否清晰”给中性分。

## 3. 企业强度 `enterprise_strength`

看企业是不是值得区域团队优先盯的样本：

- 大型或中型企业、规上企业、主体清晰：`12-20`
- 小型但标签强、主体稳、区域价值明确：`8-14`
- 规模普通、主体中性：`4-10`
- 规模弱且缺少支撑信号：`0-3`

优先证据：

- `cn_company_scale`
- `cn_company_above_scale`
- `cn_company_entity_nature`
- `cn_company_concept_labels`

建议加分信号：

- 中型或大型
- 规上企业
- 上市、高新、专精特新、技术领先、外贸等高价值标签
- 用户明确偏好的主体性质

## 4. 创新与增长信号 `innovation_signal`

看企业是否值得纳入重点关注名单，而不只是“存在于区域里”：

- 科创评分高、综合评分高，且存在成长/扩张信号：`11-15`
- 有一定科创力或扩张信号：`6-10`
- 仅有少量弱信号：`1-5`
- 没有有效证据：`0`

优先证据：

- `cn_company_tech_innovation_score`
- `cn_company_tech_innovation_composite_score`
- 增长或扩张类概念标签

银行或商机语义下，可把 `cn_company_commercial_clues` 作为增强证据，不要对所有场景默认加这条。

## 5. 可触达性 `reachability`

看区域团队后续是否便于跟进：

- 电话、邮箱、地址齐全：`7-10`
- 至少有 1-2 种有效触达方式：`4-6`
- 只有地址或信息较弱：`1-3`
- 几乎无有效触达信息：`0`

优先证据：

- `cn_company_contact_info`

对于研究团队场景，可适度降低此维度影响，但不要完全忽略。

## 6. 风险扣分 `risk_penalty`

风险越高，扣分越重：

- 风险较低或可控：`0-5`
- 中等风险：`6-12`
- 偏高风险：`13-18`
- 高风险且存在明显重负面：`19-25`

优先证据：

- `cn_company_composite_risk`
- `cn_company_justice_risk`

不要把风险结果写成绝对否定，除非命中硬性否决。

## 分层规则

- `A`：`total_score >= 65`，且 `region_fit >= 15`，未命中硬性否决
- `B`：`52-64`，或总分达到 A 但存在 1 个关键字段待核
- `C`：`38-51`
- `排除`：`< 38`，或命中硬性否决
- `待人工确认`：主体冲突、区域一致性冲突、关键字段缺失或证据互相矛盾

## 排序 Tie-Breaker

总分相同或接近时，按以下顺序稳定排序：

1. `region_fit` 更高者优先
2. `industry_fit` 更高者优先
3. `risk_penalty` 更低者优先
4. `innovation_signal` 更高者优先
5. 企业中文名称字典序作为最后的稳定顺序

## 白名单规则

- 正式 A 类白名单只收 `A`
- `B` 只能进入“候补名单”，不要混进正式 A 类
- 如果用户要求固定数量但 `A` 不足，不要用 `C` 补齐
- 若 `A` 过多，按排序规则截取前 `whitelist_size` 家，其余保留在完整排序结果中
