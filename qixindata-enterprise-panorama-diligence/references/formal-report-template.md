# Formal Report Template

正式版用于用户确认继续后的第二轮客户交付。它应建立在简版已经完成、主体已锁定、核心结论已成型的基础上。
先写 Markdown 工作稿，再导出 PDF 正式交付件。
正文直接从“执行摘要”开始，不添加“输入”“输出”“测试过程”章节。

## Writing Rules

- 正式版要比简版更完整，但仍保持客户交付口径和可执行性。
- 每个章节默认先表格、后短分析。
- 信息不足时保留章节，并明确标注“待进一步核验”。

## Export Rule

- 正式版完成后，立即导出同名 PDF。
- Markdown 仅作为工作稿和导出底稿保留。
