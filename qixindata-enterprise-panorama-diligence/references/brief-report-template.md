# Brief Report Template

默认用于第一轮客户交付。先写 Markdown 工作稿，再导出 PDF 正式交付件。
目标是让客户在 3 到 5 分钟内抓住核心事实、主要风险和下一步动作。
正文直接从“结论摘要”开始，不添加“输入”“输出”“测试过程”章节。

## Export Rule

- 简版完成后，立即导出同名 PDF。
- Markdown 仅作为工作稿保留。

## Follow-up Rule

简版 PDF 导出后，可在对话里补一句：

`简版 PDF 已生成。如需，我可以继续扩展为正式版 PDF 报告，补齐历史沿革、集团布局、经营辅助信息、风险细项和待办清单。是否继续生成正式版？`

不要把这句继续追问写进 PDF 正文。
