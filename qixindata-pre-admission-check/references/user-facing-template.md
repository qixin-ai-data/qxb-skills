# User Facing Template

在需要给客户一个“请按这个格式提交资料”的提示文案，或需要把结果做成表格时读取本文件。

## Mode 1. 通用核验模式

适合客户只想先看企业照面信息，不想先填很多资料时使用。

可直接发给客户：

```text
您可以先只提供企业基础信息，我先帮您确认主体是否真实存续，并整理企业照面信息给您。

请尽量提供：
1. 企业名称：
2. 统一社会信用代码或注册号（如有）：
3. 是总公司还是分支机构（如适用）：
4. 您希望我重点确认什么：
   例如：企业是否真实存续、是不是目标主体

如果您暂时还没有更多资料，也可以先只发企业名称，我先做一版通用核验。
```

自然语言版本：

```text
我们最近准备让一家企业进入准入流程，你先帮我看看这家公司是不是正常存续，把企业照面信息整理给我，我先确认主体对不对。
```

| 字段 | 库内信息 |
| --- | --- |

结尾默认加一句：

```text
如果您后续方便的话，也可以把营业执照、法人、地址、联系人、官网、许可证等信息发给我，我再继续帮您做第二步核验。
```

## Mode 2. 信息比对模式

适合客户已经拿到部分资料，希望和库内信息逐项核对时使用。

可直接发给客户：

```text
如果您已经拿到部分资料，我可以直接和库内数据逐项比对。

请尽量提供：
1. 企业名称：
2. 您想核对的字段或资料：
3. 您手上的具体信息：
4. 是否有内部核验规则或必须校验的项目：
5. 您希望我怎么输出：
   例如：逐项对比表、只列不一致项、按内部清单输出
```

自然语言版本：

```text
我们最近在走一家企业的供应商准入，企业名字叫比亚迪股份有限公司。现在业务同事给到我的有企业名称、官网、联系人邮箱和一版地址信息。麻烦帮我把这些信息和库里的照面数据对一下，看看哪些一致，哪些还要再核；如果方便的话，也按通用模板先给我一版主体核验结论。
```

## Natural Example

下面是一条更像真实客户会发来的消息：

```text
我们最近在走一家企业的供应商准入，企业名字叫比亚迪股份有限公司。现在业务同事给到我的只有企业名称，想先确认这家公司是不是正常存续，照面信息能不能先整理一版给我。后面如果有营业执照、联系人和官网信息，我再发你继续比对。
```

这类输入默认走 `通用核验模式`。

再比如：

```text
我们最近在走一家企业的供应商准入，企业名字叫比亚迪股份有限公司。现在我手里有官网、联系人邮箱和一版地址信息，麻烦你帮我和库里数据对一下，看看哪些一致，哪些还需要再核。
```

这类输入默认走 `信息比对模式`。

## Writing Guidance

- 客户没提供待比对字段时，不要输出“资料齐全性”。
- 客户提供了哪些字段，就比对哪些字段，不要默认扩大成完整材料清单。
- 如果客户后续想按自己的规则比，结尾要主动引导其继续提供清单。
- 让“是否可继续下一步”成为单独一行，不要藏在长段文字里。
- 对客户说话时，优先用“目前来看”“建议您补充”“如果您方便提供”“后续我可以继续协助”等更柔和的表达。
- 先说当前已经能确认的部分，再说还建议补充的部分，避免一上来就强调“不足”或“缺失”。
