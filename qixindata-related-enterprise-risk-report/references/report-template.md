# Report Template

正式报告默认使用以下结构。

## 一、执行摘要

回答 4 件事：

1. 目标主体是谁。
2. 关联圈风险是否显著。
3. 主要传导路径是什么。
4. 综合判断为高/中/低/证据不足哪一档。

建议控制在 250 到 400 字。

## 二、目标主体确认与基础快照

建议用表格呈现：

| 项目 | 内容 |
| --- | --- |
| 企业名称 | |
| 统一社会信用代码 | |
| 登记状态 | |
| 法定代表人 | |
| 所属行业 | |
| 所属集团 | |
| 关联企业数量 | |
| 实际控制企业数量 | |
| 受益所有人数量 | |
| 自身风险/关联风险概览 | |

## 三、关联圈识别结果

按三层结构写：

1. 强关联主体
2. 中关联主体
3. 弱关联主体

每层至少说明：

- 识别逻辑
- 代表主体
- 是否进入重点风险观察范围

## 四、重点传导链条分析

建议一条链一个小节，至少写 2 到 5 条最重要链路。

每条链建议包含：

- 链路名称
- 关系结构
- 命中的风险主体
- 风险类型
- 为什么能传导
- 传导强度判断

可用表格：

| 传导链条 | 关系类型 | 风险主体 | 风险信号 | 传导强度 |
| --- | --- | --- | --- | --- |

## 五、关键人物关联风险观察

仅展开关键人物，不要罗列全部人员。

优先选：

- 法定代表人
- 实际控制人
- 董事长/经理/核心高管

建议表格：

| 人物 | 目标企业角色 | 外部关联概览 | 关联企业风险概览 | 传导判断 |
| --- | --- | --- | --- | --- |

## 六、重点关联主体风险样本

只放代表样本，不要把全部明细贴进去。

每个主体建议写：

- 主体名称
- 与目标主体关系
- 主要风险类型
- 最新/最重样本
- 是否影响合作、授信、采购或交易安全

## 七、传导风险综合判断

建议分 4 个维度打表：

| 维度 | 等级 | 依据 |
| --- | --- | --- |
| 关系强度 | | |
| 风险严重度 | | |
| 风险集中度 | | |
| 现实传导可能性 | | |

最后给出总判断：

- 高传导风险
- 中传导风险
- 低传导风险
- 当前证据不足

## 八、边界说明

必须说明：

- 哪些接口/维度只看到聚合摘要
- 哪些主体尚未逐条穿透
- 哪些弱关系不能单独作为高强度结论依据

## 九、客户建议

建议给 3 条以内动作建议，优先：

1. 是否将哪些关联主体纳入联合审查
2. 是否对哪些人物/主体做专项穿透
3. 是否设定合作前置条件或持续监测机制
