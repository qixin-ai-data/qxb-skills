# 测试样例

以下内容用于测试这个 skill 的触发、流程和输出结构。
所有企业分数、分层、白名单标记和建议动作都只是演示值，用来验证格式与逻辑，不代表真实查询结果。正式执行时，必须重新调用 MCP 获取实时数据后再下结论。

## 样例 1：银行对公客户经理常规筛单

### 建议测试提示词

```text
我们客户经理这周要跑一批对公客户，你帮我挑出更值得优先拜访的企业，最好直接给我一版 A 类正式白名单。

这次主要看苏州、无锡、常州，偏工业自动化、新能源装备、智能制造这类企业。优先看独立企业主体，规模大一些、规上或标签比较清晰的企业可以排前面。重点看开户、综合授信、流动资金贷款、银承、票据、结算、现金管理这些机会，风险太高的先别放进正式白名单。

这批企业你先帮我排一下：
苏州汇川技术有限公司
博众精工科技股份有限公司
江苏卓胜微电子股份有限公司
苏州天准科技股份有限公司
某某智能制造服务中心分公司
无锡先导智能装备股份有限公司

最后给我：
1. 为什么这么排
2. A 类正式白名单
3. 完整排序结果
4. 哪些企业适合先主打开户和结算
5. 哪些企业更适合主打授信和票据
6. 哪些还需要人工再看一下
```

### 这个样例主要验证什么

- 是否自动识别为 `bank-rm`
- 是否能从自然语言里抽取区域、行业、主体、规模、风险和银行产品偏好
- 是否优先解释 `开户`、`综合授信`、`银承/票据`、`结算/现金管理` 等切入点
- 是否把明显分支机构降到 `待人工确认` 或排除
- 是否同时输出正式白名单、候补名单和完整排序

## 样例 2：更强授信导向的客户经理场景

### 建议测试提示词

```text
帮我从这批企业里筛出更适合客户经理本周先推进综合授信的客户，最后给我 5 家本周优先拜访名单，再补一个候补名单。

这轮更关注综合授信、流贷、项目贷、银承、票据池、贴现这些机会。优先看制造业、设备类企业和项目建设活跃的企业。开户和结算也要看，但不是第一优先。风险高的别直接进正式白名单。

企业名单如下：
苏州汇川技术有限公司
无锡先导智能装备股份有限公司
博众精工科技股份有限公司
苏州天准科技股份有限公司
宁德时代新能源科技股份有限公司

请直接告诉我：
1. 本周优先拜访名单
2. 候补名单
3. 每家企业更适合主打哪类授信或票据业务
4. 哪些企业虽然价值高，但建议先做风险复核再推进
```

### 这个样例主要验证什么

- 是否把 `综合授信`、`流贷`、`项目贷`、`银承`、`贴现` 识别为核心排序维度
- 是否优先调用 `cn_company_commercial_clues`
- 是否把“机会强但风险偏高”的样本放入 `候补名单` 而不是正式白名单
