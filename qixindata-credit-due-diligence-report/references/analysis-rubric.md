# 授信尽调分析口径 v1

在需要统一授信结论口径、收敛风险表述或处理信息冲突时读取本文件。

## Fixed Dimensions

固定按下表给出结论，不要临时自定义评分框架：

| 维度 | 必答问题 | 默认结论档位 |
| --- | --- | --- |
| 主体可信度 | 能否唯一确认本次授信对象，且当前仍真实存续 | 清晰 / 基本清晰 / 存在歧义 / 主体异常 |
| 控制链与治理透明度 | 谁控制、谁受益、谁在经营决策链上 | 清晰 / 部分清晰 / 口径差异 / 不清晰 |
| 经营与资质支撑度 | 是否存在持续经营基础，且关键资质或许可可核 | 充分 / 基本充分 / 不足 / 关键缺口 |
| 财务可验证程度 | 能否用公开数据观察收入、利润、负债、现金流或替代经营指标 | 较强 / 一般 / 较弱 / 不足以判断 |
| 公开风险暴露水平 | 是否存在司法、税务、处罚、异常经营、资产负担等重要风险 | 低 / 中 / 高 / 高且需立即复核 |
| 外部经营与供应链稳定性 | 是否存在客户、供应商、上下游或其他外部经营线索支撑 | 较稳定 / 有一定支撑 / 线索有限 / 无法判断 |
| 综合授信建议 | 是否具备进入下一步授信流程的基础 | 建议进入评审 / 补充材料后进入评审 / 建议进一步专项核查 / 当前不建议推进 |

## Evidence Priority

证据冲突时，按以下优先级保守处理：

1. 统一社会信用代码、注册号、正式企业全称
2. 工商照面、基础工商报告、法定代表人、注册地址
3. 股东、实控人、受益人、集团成员、分支关系
4. 资质许可、纳税记录、社保披露、域名备案、年报网址
5. 新闻、供应链、客户、供应商、概念标签、外围经营线索

低优先级证据不要推翻高优先级强标识；若冲突明显，直接写“公开资料存在口径差异”。

## Credit Interpretation Rules

- 把“经营状态正常”理解为“公开工商状态仍在存续”，不要把它等同于授信无风险。
- 把启信分、综合风险分、合同违约指数、空壳指数、主体评级视为辅助信号，不要单独拿某一分值作为最终授信结论。
- 把客户、供应商、上下游信息视为经营活跃度和交易网络线索，不要写成已证实的合同履约事实。
- 把“未检索到明确负面事件”写成“当前未检索到明确负面事件，不代表无风险，建议持续关注”。
- 把“未检索到资质或许可”写成“当前公开可核信息未见相关资质或许可，建议结合用户内部资料复核”。

## Financial Interpretation Rules

- 优先把财务三表和财务指标用于上市企业或有公开财务披露的主体。
- 若财务指标可得，优先概括最近 `1` 到 `3` 个报告期的收入、净利润、资产负债率、总资产、净现金流和趋势方向。
- 若财务数据缺失，不要据此写“经营差”或“无偿债能力”；统一降级为“财务公开数据有限，建议结合内部报表、审计报告或授信材料进一步核验”。
- 若只能拿到替代信号，优先用纳税 A 级、纳税人类型、社保披露、企业规模、主营业务和供应链线索描述经营支撑度。

## Trigger Rules For The Final Suggestion

- 满足以下条件时，优先给 `建议进入评审`：
  - 主体清晰且真实存续
  - 控制链无重大口径冲突
  - 关键风险未出现硬性阻断项
  - 底稿核心章节已有足够公开信息支撑

- 满足以下条件时，优先给 `补充材料后进入评审`：
  - 主体已清晰或基本清晰
  - 风险未到明显阻断级别
  - 缺口集中在可补材料，如资质复印件、最新财务材料、集团口径说明

- 出现以下任一情形时，优先给 `建议进一步专项核查`：
  - 控制链复杂且口径冲突明显
  - 风险聚集但尚不足以直接否定
  - 财务、税务、许可或关系链存在明显信息缺口
  - 用户明确要求重点看某个高敏主题

- 出现以下任一情形时，优先给 `当前不建议推进`：
  - 注销、吊销、撤销、清算等明显异常存续状态
  - 主体不匹配或无法排除重大主体混淆
  - 明显严重违法、失信、重大税收违法、密集执行等硬风险集中命中
  - 关键牌照或资质明确缺失且属于场景硬门槛

## Writing Constraints

- 保持授信审查语言，不要写营销式、绝对化或带有保证意味的表达。
- 至少显式写出 `1` 到 `3` 个最关键的授信关注点或阻断点。
- 缺失信息时写“公开可核信息不足”或“建议补充”，不要写“无”或“已排除”。
- 不要输出额度建议、期限建议、担保结构设计或法律性质判断，除非用户另行明确要求且证据充分。
