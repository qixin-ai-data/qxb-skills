# 授信尽调底稿模板 v1

正式文件命名：

`[企业简称]_授信尽调底稿_[YYYY-MM-DD].pdf`

同名 Markdown 工作稿：

`[企业简称]_授信尽调底稿_[YYYY-MM-DD].md`

字段无数据时写“基于当前可核验的公开信息，相关资料暂不充分”或“财务公开数据有限”，不要写技术原因。

## 封面

- 标题：`[企业简称] 授信尽调底稿`
- 副标题：主体识别、经营支撑、风险排查与授信建议
- 日期：`[YYYY-MM-DD]`
- 可选：在右上角展示品牌 logo
