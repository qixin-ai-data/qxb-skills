# Evidence Table Templates

在用户明确要求 `处罚明细`、`资质明细`、`许可明细`、`证据表`、`附表`，或这些证据已经实际影响排序和结论时读取本文件。

## Always-On Rules

- 先给 `候选企业总表` 和 `评分卡`，再追加证据附表；不要只输出证据表而没有结论。
- 证据附表只展示实际核到的字段；没有单独字段时写 `-`，不要从长正文里主观猜测。
- 同一张表里的多家企业必须使用同一列定义。
- 金额字段优先保留接口原始口径。若接口字段已是 `万元`，就按 `万元` 展示；不要再自行换算成人民币元。
- 默认按 `日期倒序` 展示最近记录；如果记录过多，先写总数，再展示最近 `5 到 10` 条。
- 默认显式标注 `当前公示` 或 `历史公示`，避免把历史记录误判为当前风险。

## Punishment Table

优先使用：

- `cn_company_administrative_penalties`
- 需要单独补环保处罚时，再加 `cn_company_environmental_penalties`

### Recommended Columns

| 列名 | 字段来源 | 说明 |
| --- | --- | --- |
| 企业 | 企业名称 | 使用正式主体名称 |
| 处罚决定日期 | `date` 或 `penalty_date` | 按接口原字段展示 |
| 公示日期 | `publish_date` | 没有则写 `-` |
| 处罚类型 | `push_type_one` / `push_type_two` / `penalty_type` | 能展示更具体类型时优先更具体 |
| 处罚事由 | `reason` | 用于一句话说明为什么被处罚 |
| 处罚机关 | `department` | 决定或发布机关 |
| 决定书文号 | `number` | 没有则写 `-` |
| 罚款金额（万元） | `punish_amnt` | 结构化金额字段，优先使用 |
| 没收违法所得（万元） | `illegal_income_amnt` | 没有则写 `-` |
| 当前/历史公示 | `disabled` | `0` 写“当前公示”，`1` 写“历史公示” |
| 备注 | `source` / `content` | 只保留一句补充说明，不贴大段正文 |

### Rendering Rules

- `punish_amnt` 为 `0` 时，只有在接口明确返回 `0` 才写 `0`；缺字段时写 `-`。
- `reason` 过长时，保留前半句核心违法事由，不要整段复制。
- 若行政处罚和环保处罚同时存在，优先分成两张表：`行政处罚信息表` 与 `环保处罚信息表`。

## Certificate Table

优先使用：

- `cn_company_certificates`

### Recommended Columns

| 列名 | 字段来源 | 说明 |
| --- | --- | --- |
| 企业 | 企业名称 | 使用正式主体名称 |
| 证书类型 | `type` | 如 ISO9001、环境管理体系认证等 |
| 证书编号 | `num` | 原始编号 |
| 发证日期 | `issue_date` | 按接口原字段展示 |
| 有效期截止 | `validity_end` | 没有则写 `-` |
| 状态 | `status` | 如有效、注销、过期 |
| 发证机关 | `issue_unit` | 原字段展示 |
| 备注 | `remarks` | 没有则写 `-` |

### Rendering Rules

- 当用户只是想看“资质概况”时，先给总数和最近 `5` 条。
- 当用户明确指定某类体系证书或产品认证时，优先筛该类型，再补总数。
- `状态` 不是 `有效` 的证书可以保留，但必须显式标注，避免误算成正向证据。

## License Table

优先使用：

- `cn_company_administrative_licenses`

### Recommended Columns

| 列名 | 字段来源 | 说明 |
| --- | --- | --- |
| 企业 | 企业名称 | 使用正式主体名称 |
| 许可名称 | `name` | 没有则写 `-` |
| 许可编号 | `number` | 没有则写 `-` |
| 开始日期 | `startDate` | 按接口原字段展示 |
| 截止日期 | `endDate` | 没有则写 `-` |
| 许可机关 | `department` | 原字段展示 |
| 当前/历史公示 | `disabled` | `0` 写“当前公示”，`1` 写“历史公示” |
| 状态 | `status` | 如有效、无效 |
| 备注 | `content` / `source` | 保留最短必要说明 |

### Rendering Rules

- `content` 很长时，只保留与本轮判断最相关的一小段说明。
- 如果用户重点看“当前可用许可”，优先展示 `disabled = 0` 且 `status = 有效` 的记录。
- 如果许可数量很大，先给 `总数 + 最近记录`，不要整表铺满。

## Suggested Summary Sentences

- 处罚表后可用：
  - `当前公开可核行政处罚共 X 条，本表展示最近 Y 条。`
  - `处罚金额字段按接口原始万元口径展示。`

- 资质表后可用：
  - `公开可核资质证书共 X 条，本表展示最近 Y 条或与本轮判断最相关的证书。`

- 许可表后可用：
  - `公开可核行政许可共 X 条，本表展示最近 Y 条或当前公示且状态有效的记录。`
