# Opportunity Prioritization Framework

## Hard Stop Rules

命中以下任一条件时，默认不进入高优先级机会清单：

- 工商状态为 `注销`、`吊销`、`撤销`、`清算` 等非正常存续状态。
- 重点客户主体解析失败，或重点客户与机会主体关系不清且无法确认。
- 明显是 `分公司`、`营业部`、`门店` 等分支主体，且用户没有明确允许分支机会。
- 综合风险或聚合风险明显过高，且没有足够正向证据对冲。
- 用户显式给出 `不再跟进`、`黑名单`、`禁止触达` 等硬性排除规则。

## Score Dimensions

机会总分为：

```text
opportunity_score =
  anchor_value_score +
  relation_proximity_score +
  signal_strength_score +
  product_gap_score +
  execution_readiness_score -
  risk_penalty
```

### `anchor_value_score` `0-20`

- `15-20`：重点客户本体体量大、行业地位高、属于战略客群或明确白名单。
- `8-14`：重点客户价值中等，值得跟进但不属于头部客群。
- `0-7`：重点客户价值证据较弱。

### `relation_proximity_score` `0-15`

- `13-15`：重点客户本体或直接参股控股子公司。
- `9-12`：集团成员，关系清晰。
- `5-8`：同实控企业或关系较远的关联主体。
- `0-4`：关系不清或只能弱推断。

### `signal_strength_score` `0-30`

- `22-30`：出现明确开户、授信、保理、票据、进出口、跨境、招投标、供应链等强信号。
- `12-21`：存在部分机会信号，但证据不够集中。
- `0-11`：只有弱信号或通用经营信息。

### `product_gap_score` `0-20`

- `15-20`：用户明确给了当前产品覆盖，且机会类型与现有覆盖存在清晰缺口。
- `8-14`：用户给了部分当前产品信息，可以大致判断存在产品切入口。
- `0-7`：没有当前产品信息，只能保守判断为潜在机会。

### `execution_readiness_score` `0-15`

- `11-15`：联系方式可得、重点客户归属清晰、下一步动作明确。
- `6-10`：能够跟进，但仍需补一部分执行条件。
- `0-5`：可触达性或动作落点不清。

### `risk_penalty` `0-30`

- `20-30`：明显高风险主体，存在执行、失信、重大处罚、严重异常等红旗。
- `10-19`：存在一定风险项，需要人工复核。
- `0-9`：风险总体可控。

## Opportunity Class Mapping

- `A`：`opportunity_score >= 70`，机会类型明确，证据足够，风险可控。
- `B`：`55-69`，机会存在，但需要再补 1-2 个关键信息点。
- `C`：`40-54`，只有弱信号，建议观察。
- `排除`：`< 40` 或命中硬性否决项。
- `待人工确认`：主体冲突、关系不清、缺少关键字段或风险证据矛盾。

## Type-Specific Heuristics

### 跨境机会

优先看这些证据：

- `cn_company_import_export` 命中。
- 主营业务或经营范围包含外贸、进出口、海外业务。
- 供应链或客户生态有明显跨境场景。

### 开户机会

优先看这些证据：

- `cn_company_commercial_clues` 出现开户、结算、拓客相关信号。
- 机会主体是重点客户的子公司或集团成员，且当前产品覆盖信息里未见开户/结算。

### 授信机会

优先看这些证据：

- `cn_company_commercial_clues` 出现授信、融资、保理、票据等信号。
- 近期有招投标、项目融资、应收账款、供应链资金需求等场景。
- 风险需比开户或交叉销售场景更严格。

### 业务交叉机会

优先看这些证据：

- 现有合作产品较少，但主营、上下游、集团结构说明有更多产品切入口。
- 用户明确给出想拓展的产品方向。
- 当前缺少产品覆盖信息时，只能写成 `潜在交叉销售机会`。

## Evidence Writing Rules

- 先写重点客户本体价值，再写机会主体和关系类型。
- 机会证据单独写：商机线索、进出口、招投标、供应链、集团关系等。
- 风险证据单独写：综合风险、聚合风险、内部风险标签。
- 下一步单独写：先开户、先补跨境资料、先做授信复核、先人工确认关系。

不要用“优质客户”“潜力大”“建议重点关注”这类空泛词替代证据。
