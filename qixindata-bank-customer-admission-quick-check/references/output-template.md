# 输出模板

完成快速筛查时，按以下四段输出，不增不减。

```markdown
# 银行客户准入快速筛查
## 1. 准入结论
- 结论：建议进入下一步 / 建议补充材料 / 建议升级审查 / 不建议准入
- 判断说明：用 1 到 2 句话说明主体是否已确认、是否命中阻断项、为什么落到当前结论。

## 2. 主体确认与基本信息
- 主体确认：已确认 / 存在歧义 / 未找到可靠信息
- 主体说明：说明是唯一命中，还是通过统一社会信用代码、注册号、法定代表人、登记状态、联系方式等交叉锁定为同一主体。
- 企业名称：
- 统一社会信用代码：
- 法定代表人：
- 登记状态：
- 成立日期：
- 联系方式：

## 3. 准入风险摘要
- 登记状态/注销吊销风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 司法执行风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 经营异常风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 行政处罚风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 税务风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 股权冻结风险：命中相关记录 / 未命中相关记录 / 未找到可靠信息 / 当前接口未覆盖 / 本次接口调用失败
- 备注：只写 1 到 3 条真正影响准入判断的事实，不写长段解释。

## 4. 接口证据与下一步建议
| 证据摘要 | 来源 |
| --- | --- |
| 主体解析与候选情况 | `qxb_op_enterprise_resolve` |
| 基础工商照面 | `cn_company_registration_face` |
| 联系方式与地址线索 | `cn_company_contact_info` |
| 影响结论的风险明细或聚合结果 | `具体接口名` |

- 下一步建议：写成动作句，例如“建议进入开户资料复核”“建议补充营业执照与税务合规材料”“建议转法务/合规升级审查”“建议暂缓准入”。
```

## 模板使用规则

- 保持每段简短。
- 如字段缺失，明确写 `未找到可靠信息`。
- 不要在第 1 到第 3 段直接写接口名。
- 若只出现同名重复候选，但已被统一社会信用代码或注册号交叉锁定为同一主体，应写 `主体确认：已确认`，并在“主体说明”中解释。
- 若关键接口失败影响结论，需在第 4 段写出失败接口和影响，不要伪装成“未命中相关记录”。
